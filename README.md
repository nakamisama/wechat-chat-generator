# 微信聊天生成器 · 网页版

用于生成工程稽核材料所需的微信聊天记录截图。**纯网页版，点按钮直接下载 PNG**，不需要安装任何东西、不联网。

文字由浏览器 Canvas 真实绘制，**100% 准确无错别字**。

---

## 快速开始

### 方式一：双击打开（最简单）

双击 `index.html`，浏览器即可使用。

- ✅ 改昵称、选头像、增删消息、切手机、下载图片
- ❌ "预设项目"按钮会失败（浏览器本地文件限制）

### 方式二：本地服务器（推荐，功能完整）

```bash
cd 微信聊天生成器
python -m http.server 8000
```

浏览器打开 <http://localhost:8000>，所有功能正常，自动加载预设。

## 核心新功能

### 1. 群聊支持

勾选「启用群聊」后：

- 可添加 **任意数量群成员**，每人独立头像、昵称
- 指定谁是"我"（绿色气泡，右侧）
- 群聊中对方消息会 **在气泡上方显示昵称**，与真实微信一致
- 导航栏标题显示 `群名称(人数)`
- 每条消息可单独指定由哪个成员发出

### 2. 真实微信时间戳规则

不再手写"2025年8月14日 上午9:12"，而是给每条消息一个真实时间（ISO 格式），**时间戳由系统按真实微信规则自动生成**：

| 消息时间 | 截图当天为 9月20日时显示 |
|---------|----------------------|
| 9月20日 09:12 | `上午 9:12` |
| 9月19日 16:20 | `昨天 下午 4:20` |
| 9月15日 10:00 | `星期一 上午 10:00` |
| 8月14日 09:12 | `8月14日 上午 9:12` |
| 2024年8月14日 | `2024年8月14日 上午 9:12` |

**截图当天**由左侧「截图当天」日期控制。

### 3. 跨天自然截图

同一张截图里可以自然包含 **多天对话**，例如：

```
9月28日 下午 2:35
  孙师傅：设备到了，我和赵工一起开箱核验
  王主任：好，施工期间注意安全

星期四 下午 5:12
  孙师傅：镇中心几个点位装完了

上午 9:05
  赵工：各位，摄像头全部装好调试完了
```

这就是真实微信聊天记录的样子。

### 4. 智能分段下载

「生成并下载全部」会：

- 按 **日期分组** 自动切分
- 消息过少（<3条）的日期自动并入下一张，形成跨天截图
- 保证每张截图内容不重复

点「改」会依次询问：

1. **发送人**（群聊时）：输入成员序号

## 项目预设（本地保留）

> 项目配置含真实人员与项目信息，**不入 git**，只保留在本地。
> 仓库里只有脱敏模板 `configs/_template.json`。

本地配置支持两种形态：

| 形态 | 说明 |
|------|------|
| 群聊 | 手机端 / PC 端均可，成员任意数量，可指定谁是"我" |
| 单聊 | 手机端 / PC 端均可，仅对方与我 |

典型配置项：

| 字段 | 说明 |
|------|------|
| `mode` | `mobile`（手机） / `desktop`（PC） |
| `winW` / `winH` | PC 端窗口尺寸，如 `1080 × 820` |
| `captureDate` | 截图当天，决定"昨天/星期X/月日"的基准 |
| `messages[].time` | ISO 时间，PC 端显示 24 小时制 |

### 配置迁移（换电脑）

```bash
# 列出本地所有项目配置
python project_config.py list

# 旧电脑：把配置、项目头像、现场照片打包
python project_config.py export -o D:/备份/微信配置.zip

# 新电脑：clone 仓库后还原
python project_config.py import -i D:/备份/微信配置.zip
```

打包内容：`configs/*.json`、`avatars/projects/`、`assets/gen_*.jpg|png`。

## Windows 电脑版渲染

`js/desktop-render.js` 按真实 Windows 微信截图重做：

- 标题栏：左联系人/群名，右上最小化/最大化/关闭；第二行右侧语音/视频/更多
- 聊天区浅灰底、白色气泡、群聊显示昵称
- 文件卡片：文件名 + 大小 + 类型图标（DOC/XLS/PDF）+「微信电脑版」页脚
- 底部白色输入区：表情/立方体/文件夹/剪刀 + 右下「发送(S)」
- 时间：**24 小时制**（`14:40`），跨天显示 `9月8日 09:30`、`昨天 11:20`

窗口尺寸可通过配置项调整（默认 1440×908）：

```json
{ "mode": "desktop", "winW": 1080, "winH": 820 }
```

### 分屏截图

`regen_*.py` 采用固定步进滚动分屏：以可视高度为一步向下滚动，
若顶部落在消息中间则上对齐到该条起点，末屏贴底，保证不重叠、不遗漏。

## JSON 配置格式

```json
{
  "title": "项目名",
  "device": "xiaomi-14pro",
  "statusBarTime": "9:30",
  "captureDate": "2025-10-15",
  "timeThresholdMin": 10,
  "longMode": false,
  "group": {
    "enabled": true,
    "name": "项目沟通群",
    "members": [
      {"name": "王主任", "avatar": "avatars/real/male_02_young_officer.png", "isMe": false},
      {"name": "赵工", "avatar": "avatars/scenery/scene_03_lake.png", "isMe": true}
    ]
  },
  "opponent": {"name": "王主任", "avatar": "..."},
  "me": {"name": "赵工", "avatar": "..."},
  "messages": [
    {"type": "text", "from": "other", "fromId": "王主任", "time": "2025-10-15T09:30", "text": "..."},
    {"type": "text", "from": "me", "fromId": "赵工", "time": "2025-10-15T09:32", "text": "..."}
  ]
}
```

**关键字段**：
- `time`：ISO 格式，决定显示成"昨天/星期X/月日"
- `fromId`：群聊时指定发送人姓名
- `captureDate`：截图当天，决定相对时间显示

## 常见问题

**Q: 双击打开后头像不显示？**
A: 用 `python -m http.server 8000` 起服务器再访问。

**Q: 时间戳显示不对？**
A: 检查左侧「截图当天」日期是否设置正确。

**Q: 想让某张截图从中间某条开始？**
A: 在「首条消息序号」填数字（从1开始）。

**Q: 群聊里怎么改某条消息的发送人？**
A: 点消息的「改」，第一步会问发送人序号。

**Q: 导出的图片模糊？**
A: 导出倍数改 4 倍。
